# Sample Job Ad — Forward Deployed Engineer

**Company:** Meridian Robotics (fictional)
**Location:** Toronto / Remote
**Seniority:** Senior

## About the role

You'll embed with enterprise customers to deploy our robotics-fleet telemetry
platform. Part engineer, part consultant: you scope requirements on-site, build
integrations against messy customer data, and feed product gaps back to core
engineering.

## Responsibilities

- Own end-to-end technical deployments for 3–5 enterprise customers
- Build data pipelines and APIs that integrate customer systems (ERP, WMS, custom
  Postgres/Kafka estates) with our platform
- Write production code (Python/TypeScript) and debug live systems during rollouts
- Translate field findings into roadmap input; occasionally prototype LLM-assisted
  tooling for ops teams

## Requirements

- 5+ years software engineering, incl. customer-facing or solutions work
- Strong Python + SQL; comfortable with Kubernetes and cloud infra (AWS preferred)
- Experience with event-driven systems (Kafka or similar)
- Clear communicator; can context-switch between code and stakeholder meetings
- Bonus: applied LLM/RAG experience, Terraform, observability tooling

## Nice to have

- Startup or consultancy background
- Experience deploying into air-gapped / regulated environments
